# Exercícios Bloco 02

Exercícios focados em módulos do Python

## ex006: Tocando um MP3 com python

Programa que abre e reproduz o áudio MP3 usando a biblioteca 'pygame-ce'

### Requisitos
- Python 3
- Biblioteca 'pygame-ce'

### Instalação

Instale a biblioteca com `pip install pygame-ce`.

### Atenção: o MP3 não está incluído

O arquivo de áudio não foi enviado ao repositório por questão de direitos autorais. Para o programa funcionar:

1. Coloque um MP3 seu dentro da pasta `ExerciciosBloco02`.
2. No `ex006.py`, troque o nome do arquivo na linha do `pygame.mixer.music.load(...)` pelo nome do seu MP3.
3. Execute o programa a partir da pasta raiz do projeto, porque o caminho no código começa com `ExerciciosBloco02/`.
